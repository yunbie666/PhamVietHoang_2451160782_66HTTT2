📋 Xem CSS code 
/* ✅ Hiệu ứng 1: Card hover */
.demo-card {
  transition: all 0.3s ease;
}
.demo-card:hover {
  transform: translateY(-8px);
  box-shadow: 0 12px 36px rgba(0,0,0,0.18);
}

/* ✅ Hiệu ứng 3: Image zoom */
.card-img-container {
  overflow: hidden; /* BẮT BUỘC — giữ ảnh trong hộp */
}
.card-img-container img {
  transition: transform 0.4s ease;
}
.demo-card:hover .card-img-container img {
  transform: scale(1.1); /* Zoom 110% */
}

Hiệu ứng 2 — Button Hover

✋ Hover vào các nút để thấy màu đổi mượt + scale(1.05)

📋 Xem CSS code 
/* ✅ Hiệu ứng 2: Button hover */
.btn-buy {
  background: #c0392b;
  color: #fff;
  transition: background-color 0.3s ease,
              transform 0.2s ease,
              color 0.3s ease;
}
.btn-buy:hover {
  background: #e67e22; /* Đổi màu mượt */
  transform: scale(1.05); /* Phóng to nhẹ */
}

Hiệu ứng 4 — Loading Spinner (@keyframes)

Các spinner dùng @keyframes spin + animation: spin 1s linear infinite

Cơ bản
linear
Biến thể
ease-in-out
Pulse
scale+opacity
In button
📋 Xem CSS code 
/* ✅ Hiệu ứng 4: Keyframes spin */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

.spinner {
  width: 48px;
  height: 48px;
  border: 4px solid #e0e0e0;
  border-top-color: #c0392b; /* Phần màu */
  border-radius: 50%;

  /* animation: tên | duration | timing | iteration */
  animation: spin 1s linear infinite;
}

📋 Xem CSS code 
/* ✅ Hiệu ứng 5: Fade-in từ dưới lên */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(24px); /* Bắt đầu thấp hơn 24px */
  }
  to {
    opacity: 1;
    transform: translateY(0); /* Về vị trí bình thường */
  }
}

.fade-item {
  animation: fadeInUp 0.6s ease both;
}

/* Stagger: mỗi item xuất hiện trễ hơn 0.15s */
.fade-item:nth-child(1) { animation-delay: 0.0s; }
.fade-item:nth-child(2) { animation-delay: 0.15s; }
.fade-item:nth-child(3) { animation-delay: 0.30s; }
.fade-item:nth-child(4) { animation-delay: 0.45s; }
